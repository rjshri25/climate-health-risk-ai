Intelligent Urban Health Risk Prediction System

An AI-powered system that predicts community-level health risks using real-time weather and air quality data.

---

 Problem:

Urban health systems are reactive — action is taken only after diseases spread.

This project solves that by predicting health risks before outbreaks happen using environmental data.

 Solution:

The system collects real-time data like:
- Temperature
- Humidity
- Rainfall
- Air Quality Index (AQI)
- UV Index

Machine Learning models analyze this data to:
- Predict health risk levels
- Generate early warnings
- Provide preventive insights

---

 Features

- 🌐 Real-time data using APIs
- 🤖 AI-based health risk prediction
- 📊 Interactive dashboard
- ⚡ Early warning system
- 🌍 Works for any city (location-independent)

---

Woking:

1. Fetch environmental data via APIs  
2. Process & clean data  
3. Apply ML model for prediction  
4. Generate health risk output  
5. Display results on dashboard  

---

Tech Stack:

- Frontend: React.js  
- Backend: Node.js / Express  
- Database: MongoDB  
- AI/ML: Python (Scikit-learn, Pandas, NumPy)  
- APIs: Weather & AQI APIs
